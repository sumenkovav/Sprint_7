# Финальный проект 7 спринта: Автотесты API учебного сервиса Яндекс Самокат

> **Автор:** Александр Суменков 55-ая когорта

Это репозиторий с автотестами на Python (Pytest + Allure) для проверки API учебного сервиса Яндекс Самокат. Проект демонстрирует навыки написания параметризованных тестов, работы с фикстурами, генерации отчётов и организации структуры проекта.

## 📋 Что уже реализовано

*   ✅ Написана логика тестов в папке `tests/`.
*   ✅ Настроены глобальные фикстуры и интеграция с Allure в `conftest.py`.
*   ✅ Реализована работа с тестовыми данными через папку `data/` и вспомогательные функции в `helpers/`.
*   ✅ Автоматически генерируются результаты тестирования в папку `allure-results/`.


## ⚠️ Важное примечание по окружению

Для корректной работы проекта **требуется версия Python 3.11 или 3.12**.

> ⚠️ **Почему это важно:** Библиотека `allure-pytest` в текущей версии зависит от модуля `distutils`, который удалён в Python 3.13+. Запуск на новых версиях приведёт к ошибке `ModuleNotFoundError`.

## 📊 Отчёт Allure

В проекте реализована интеграция с Allure для формирования отчётов о тестировании.

### Важное примечание
Папки `allure-results/` (сырые данные) и `allure-report/` (HTML-отчёт) **намеренно исключены** из репозитория и добавлены в `.gitignore`.

### Как получить отчёт?


1.  **Запустите тесты**, чтобы сгенерировать данные:
    ```powershell
    pytest tests/ -v --alluredir=allure-results
    ```
    *(Убедитесь, что в папке `allure-results` появились JSON-файлы).*

2.  **Сгенерируйте отчёт** (требуется установленный Allure CLI):
    ```powershell
    allure generate allure-results -o allure-report --clean
    ```
    Или запустите интерактивный сервер:
    ```powershell
    allure serve allure-results
